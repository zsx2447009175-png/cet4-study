## 2026-05-22 紧急修复 — 页面空白问题

### Bug: 网页完全空白
- **根因**: `renderVocab()` 中第 1075 行（now 1075）的词卡 HTML 模板：
  ```javascript
  toggleBookmark(this.getAttribute('data-word'),this)
  ```
  `'data-word'` 的单引号破坏了外层 JS 单引号字符串 → 语法错误 → 页面白屏
- **一级影响**: 这是 `renderVocab()` 函数，在 `updateUI()` 中调用，`updateUI()` 在 `DOMContentLoaded` 中调用 → 任何日期进入都白屏

### 修复
1. **index.html 直接修复**: `'data-word'` → `\'data-word\'`（JS 转义）
2. **build_v3.py 源模板修复**: Python `'''...'''` 中 `\'` 会被解释为 `'`，需用 `\\'` 双转义才能在生成的 JS 中输出 `\'`

### 部署
- SHA: 715cb5518a
- JS括号: 628/628 平衡（与之前一致）
